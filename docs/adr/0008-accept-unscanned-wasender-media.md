# Accept unscanned Wasender media within hard size limits

The MVP stores all inbound media types returned for an authenticated Wasender delivery without malware scanning or a strict file-type allowlist. Stored Media is always treated as opaque, untrusted content: the platform never executes or renders it server-side, serves MCP-readable objects only through authorization-checked MCP resources, disables content sniffing, and presents downloads as attachments. Provider downloads require HTTPS and an exact approved host, reject private-network targets and unsafe redirects, enforce timeouts, hash actual bytes, and abort actual streamed bytes above `5,000,000` bytes (5 MB) for images, `16,000,000` bytes (16 MB) for audio, `50,000,000` bytes (50 MB) for video, `100,000,000` bytes (100 MB) for documents, or `100,000` bytes (100 KB) for stickers. A `ready` state requires a verified actual byte size and normalized MIME type and means only that these transport and structural checks completed; it is independent of the separate 16 MiB MCP delivery limit, which only the video and document ingestion ceilings exceed, and is not a malware-safety assertion.
