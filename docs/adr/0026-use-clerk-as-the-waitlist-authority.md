# Use Clerk as the waitlist authority

Clerk Waitlist mode is the sole applicant and approval authority for private-beta access. A User who can authenticate has already passed that gate, so the API bootstraps or recovers their Personal Account without a second application-level onboarding gate, and Neon stores no waitlist or applicant ordering. Neon still serializes each new Personal Account's full three-Connection entitlement against the vendor-approved provider session capacity. Exhausted capacity creates no Personal Account or provider resource and returns transient service unavailability until capacity increases. This supersedes ADR 0004 only where it assigned provider-capacity waitlisting to the platform; the prohibition on unapproved account sharding and bring-your-own provider credentials remains.
