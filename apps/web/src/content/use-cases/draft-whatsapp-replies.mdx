A useful reply depends on tone, prior commitments, and what the other person actually asked. An approved MCP Client can read the relevant observed conversation and prepare a draft while leaving the final wording and action with you.

## Drafting and sending are different actions

Stored Message read permission lets the MCP Client understand the conversation. It does not grant send permission. You can ask for a draft, edit it yourself, and stop there.

## Try asking

> Draft a warm reply to Marco about the proposal. Do not send it.

> Prepare a concise answer to the last question from Lucía.

> Draft a follow up that mentions our agreed deadline.

## Before anything is sent

Every outbound messaging tool invocation requires Client Confirmation. Normal describes and requests that interaction through tool metadata where supported, but does not treat it as a separate server verified security boundary.
