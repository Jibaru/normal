# Send retained PDF files

Add `send_pdf_file` beside `send_text_message` and allow the REST Send Operation route to accept the same PDF request. A caller supplies exactly one Directory recipient or Direct Address and exactly one source: strict standard Base64 bytes or an HTTPS URL without credentials or a non-default port. URL retrieval validates every redirect, rejects non-public address resolution, uses a 15-second total timeout, and counts actual response bytes. Both forms must begin with a PDF version signature and contain no more than 16 MiB. The filename is required, bounded, contains no path or control characters, and ends in `.pdf`.

Current `messages:send` authorization and selected-Connection access are checked before decoding or retrieving a PDF and are checked again when the Send Operation commits. The exact bytes, filename, destination, Connection, and grant identity enter the idempotency fingerprint; the source URL does not. Every invocation still requires Client Confirmation. A committed operation performs one provider upload followed by at most one document-send attempt. An ambiguous document-send result becomes `unknown` and is never retried automatically. A failed upload cannot have sent the WhatsApp message and is definitive for that operation.

Before the provider attempt, Normal writes the PDF as an encrypted Pending Send File under an opaque R2 key and atomically records its verified size and SHA-256 digest with the Send Operation. It counts against the existing Personal Account Stored Media quota. Rollback removes the object or durably queues deletion. Pending Send File access and deletion follow Pending Send Content: definitive pre-send failure removes it immediately; otherwise it expires at the earliest of seven days, the Message Retention Policy deadline, Connection Deletion, or Personal Account Deletion. Quota remains charged until R2 deletion is confirmed. Normal retains neither a supplied source URL nor a provider upload URL and emits neither URL, filename, nor bytes through logs, Activity Logs, errors, or telemetry.
