Names, preferences, introductions, and recommendations are easy to lose in everyday conversation. Normal lets an approved MCP Client search observed messages for the detail you need at the moment you need it.

## Search from a partial memory

Describe the people likely involved, an approximate date, and the kind of detail you remember. Ask for the relevant conversation context so you can verify names and intent.

## Try asking

> Who was I supposed to introduce Camila to?

> Which restaurant did Pedro say his mother loved?

> What gift idea did Sofía mention for Daniel?

## Private context stays protected

The WhatsApp Directory is connection scoped and protected by explicit authorization. Normal does not create a public contact profile, and the platform architecture prohibits routine operator access to private conversation content.
