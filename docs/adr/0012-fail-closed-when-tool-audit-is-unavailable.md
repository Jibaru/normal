# Fail closed when protected-operation audit is unavailable

Every protected MCP tool invocation, protected resource read, and protected API request durably creates a metadata-only Activity Log record before decrypting data, serving media, or invoking Wasender; if that write fails, the operation does not run. Results update the record before a response is released where possible, while durable Send Operations remain the source of truth for side effects that may outlive a log-update failure. Activity Logs retain safe filters, opaque references, channel, allowlisted MCP Client or API Key presentation, timing, outcome, counts, and latency for 90 days, but never duplicate message bodies, media, full phone numbers, credentials, OAuth tokens, API Key secrets, search terms, or raw provider payloads. The persisted table remains `tool_call_logs` during the additive expand; MCP behavior is unchanged.
