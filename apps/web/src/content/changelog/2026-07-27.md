description: Normal's foundation introduced secure Personal Accounts, complete WhatsApp Connection setup and recovery, scoped MCP access, and reliable WhatsApp Directory ingestion.

---

## Personal Accounts

- Users can create a Clerk-backed Personal Account, with capacity-aware private-beta waitlisting.
- Personal Account data is tenant-isolated and protected with KMS-backed envelope encryption.

## Connection lifecycle

- Added [15-minute Connection Setup](https://github.com/cuevaio/normal/commit/f1a3d30) with ephemeral QR codes, clear terminal states, and automatic cleanup for cancelled or expired setups.
- Users can disconnect and reconnect WhatsApp Connections without deleting retained history, including recovery after a page reload.

## MCP access

- [MCP Authorizations](https://github.com/cuevaio/normal/commit/7530b3d) grant explicitly selected WhatsApp Connections and independently selected permissions.
- Users can review and revoke MCP Authorizations, with recent identity reverification and rotating OAuth refresh credentials protecting changes.

## WhatsApp Directory

- Added audited `list_connections`, [`list_contacts`](https://github.com/cuevaio/normal/commit/1571d6d), and [`list_groups`](https://github.com/cuevaio/normal/commit/a9c950b) tools, limited to each MCP Authorization's grants.
- Contact and group results support secure cursor pagination and disclose stale or partial Directory projections.

## Ingestion reliability

- [Webhook Events are authenticated and encrypted](https://github.com/cuevaio/normal/commit/cd0efde) before queue processing, with per-item deduplication and evidence-ordered connection-state updates.
- Recovery handles orphaned and dead-letter work with bounded retries while recording evidence-based Ingestion Gaps.
