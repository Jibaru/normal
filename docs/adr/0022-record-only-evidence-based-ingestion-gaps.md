# Record only evidence-based ingestion gaps

Maintain connection-scoped Ingestion Gap intervals from concrete evidence, not message inactivity: provider disconnection or webhook-configuration drift found by five-minute reconciliation, verified deliveries that fail durable enqueue or bounded normalization and reach DLQ, measured ingress or Queue outages and purges, and data loss during restore. Intervals begin conservatively at the last confirmed healthy point, close only on confirmed recovery where applicable, and remain visible until they age out with the affected Message History Window because Wasender offers no backfill. Message reads return intersecting causes and call history observed rather than complete; silent provider omission while every available signal stays healthy is acknowledged as undetectable.
