# Enforce provider availability at Connection Setup

A Clerk-authenticated User can bootstrap a Personal Account without reserving provider capacity. The existing limit of three active Connection Setup or WhatsApp Connection slots per Personal Account remains product policy, but Personal Account creation does not depend on a global provider session ceiling. Provider availability is evaluated only when the private provider-control boundary provisions a Connection Setup. A definitive provider rejection leaves the Connection Setup in `provisioning_failed`, creates no WhatsApp Connection, and is presented to the User as temporary WhatsApp Connection capacity unavailability without exposing provider details. Operations manages Provider Account capacity internally. This supersedes ADR 0026 only where that decision reserved each Personal Account's full three-Connection entitlement during bootstrap.
