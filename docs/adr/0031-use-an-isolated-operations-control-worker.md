# Use an isolated operations control Worker

Use a production only `operations-control` Cloudflare Worker as the authenticated boundary for recovery availability evidence and pager delivery. Give it a zone scoped Analytics Read token, the public API smoke credential, a native Email Service binding restricted to `pager@alerts.normal.fast` and the approved pager destination, and one dedicated short lived KV namespace for message ID receipts. It may query only Cloudflare HTTP and email analytics, the public Wasender status page, and the deployed API smoke boundary. It receives no database, Neon control plane, R2, Queue, KMS, provider credential, tenant identity, or content authority. Recovery verification reads the achieved source point from a committed Neon heartbeat through the restricted verifier role and uses operations control only for aggregate availability and sampled key evidence. Pager acceptance is not proof of delivery: the caller must poll an authenticated receipt endpoint until Cloudflare reports the matching final `delivered` event. Any missing, stale, malformed, or failed evidence keeps recovery and release gates closed.
