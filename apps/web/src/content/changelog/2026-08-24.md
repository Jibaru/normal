## Image Send Operations

- [Send JPEG or PNG images](https://github.com/cuevaio/normal/commit/3fd900f) through REST or the new MCP `send_image` tool using an HTTPS URL or Base64, with an optional caption.
- Image sends support WhatsApp Recipients and Direct Addresses, enforce a 5,000,000-byte limit, and preserve existing idempotency and no-automatic-retry protections.
- Verified images are encrypted as Pending Send Files under Stored Media quota and retention rules. Source and provider URLs are never retained or logged.

## API Key creation

- [Clerk reverification](https://github.com/cuevaio/normal/commit/9a213e5) now appears above the API Key dialog and [resumes creation with the fresh session token](https://github.com/cuevaio/normal/commit/703dacb) after verification.
- Cancelled or failed reverification flows now show a clear retry message instead of silently failing.
