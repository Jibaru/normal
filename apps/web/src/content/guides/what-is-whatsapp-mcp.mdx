WhatsApp MCP is a set of tools and protected context that a compatible AI application can use through the Model Context Protocol. Normal connects one of your WhatsApp accounts, then lets you authorize an MCP Client with separate access to connection details, the WhatsApp Directory, Stored Messages, and sending.

## How it works

1. Create a WhatsApp Connection through the QR based Connection Setup.
2. Connect a compatible MCP Client and choose its exact permissions.
3. Ask the MCP Client to find context, summarize a conversation, or prepare an action.

## What you can ask

> Show my most recent WhatsApp Conversations.

> Summarize the latest messages from my family group.

> Draft a reply to Ada. Do not send it yet.

## Is MCP an AI application?

No. MCP is a standard that lets compatible AI applications use external tools and context. Provider API Credentials remain internal and are never exposed to Users or MCP Clients.
